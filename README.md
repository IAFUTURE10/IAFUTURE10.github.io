# Inicio de Código Error

Repositorio raíz de https://iafuture10.github.io/. El contenido de diagnóstico y sus herramientas se publican desde IAFUTURE10/CODIGOERROR en /CODIGOERROR/.

La raíz contiene un punto de partida legible sin JavaScript: delimitar un síntoma, registrar pruebas y reconocer situaciones que requieren detenerse. Sustituye el antiguo redireccionamiento instantáneo con anuncios sobre una pantalla sin contenido.

sitemap.xml es un índice que referencia sitemap-root.xml y el sitemap del proyecto. Ya no se copia aquí una lista de miles de rutas que puede quedar obsoleta. ads.txt conserva el identificador de vendedor existente en la raíz del host.

Para publicar, conserva GitHub Pages desde la rama principal y la raíz de este repositorio. Publica también el proyecto Código Error y comprueba sus enlaces antes de pedir una nueva revisión. Los cambios de contenido no garantizan aprobación de AdSense.
